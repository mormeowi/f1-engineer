## 📖 About

**F1 Engineer** — это вспомогательный ассистент для игры **F1 2020** от Codemasters/EA. 
Проект находится в ранней стадии разработки (v0.1), поэтому возможны баги, недоделки и странное поведение. 

> ⚠️ **Внимание:** проект делается в первую очередь для себя и ради веселья.

## 🚀 Запуск

Для запуска **не требуется** ничего устанавливать — достаточно:

1. Скачать архив с проектом (кнопка **Code → Download ZIP** на странице репозитория).
2. Распаковать архив в любую папку.
3. Открыть файл **`index.html`** в любом современном браузере (Chrome, Firefox, Edge и т.д.).

Также возможно запустить на телефоне, но возможны графические ошибки.
